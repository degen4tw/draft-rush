# Draft Rush Live

A shareable, synchronized fantasy-football draft-order race.

## Run locally
1. Install Node 20+
2. `npm install`
3. `npm start`
4. Open http://localhost:3000

## Deploy
Designed for a Node host such as Render, Railway, Fly.io, or another service that supports a long-running Node/Socket.IO process.

## Important
Rooms are currently stored in server memory. For a production version, add a persistent database and authentication for commissioner controls.
